## 后续风险与操作建议

- **输出目录权限是 advisory。** 运行 `doctor --output-dir PATH` 检查实际目标；隐私稿件先写入权限状态为 `ok` 的个人目录。仓库所有者可在明确产品策略后决定是否增加严格模式，让 `unsafe`/`unknown` 目录拒绝写出，并用 Windows/macOS/Linux 权限用例验收。
- **媒体缓存不会自动清理。** 用 `cache inspect` 查看体积，先用 `cache clean --max-age-hours N` 或 `--max-bytes N` 预览，再复核路径后加 `--apply`。
- **敏感文件扫描不覆盖 Git 历史。** 发布前独立检查完整历史及待发布树；不得将本地扫描通过写成“完整 secret scan”。
- **未经所有者决定不得发布。** 项目目前无 LICENSE、无配置的远端仓库，远端 CI 与目标 Agent 宿主尚未验收；在这些门槛关闭前保持 `NOT READY`。
